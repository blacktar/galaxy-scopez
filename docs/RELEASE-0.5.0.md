Galaxy Scopez 0.5.0 expands the scope set and makes inspection and multitouch grading easier to switch between. Includes GTap 1.2.35.

- CIE Chromaticity in xy and u′v′, with explicit input primaries and transfer settings.
- Y, RGB and CbCr waveforms; RGB, YRGB and YCbCr parades; YRGB histograms. Color toggles include source-image colours for chroma traces.
- Extents outlines on supported scopes and automatic HDR signal scales for explicitly declared PQ/HLG input.
- Independent scope Settings for zoom, Gain, Brightness, Graticule and Smooth, including duplicate scope instances and shared global defaults.
- Dedicated GPrime tab with a fixed grading surface. Hidden scopes pause processing and resume with current frame data.
- Improved waveform column coverage, GPrime waveform overlay and Contrast feedback in Clip Fullscreen.
- Compact portrait controls, consistent scope header buttons, Home Screen tab restoration, and protection against accidental iOS page zoom and text selection on scope controls.
- GS → About Galaxy Scopes shows GTap’s credits, signal-handling, placement and connection information.

Install the signed, notarized macOS package after quitting Resolve. GPrime requires Resolve Studio external scripting set to Local; native shortcuts also require the macOS permission described during setup.

Known limitation: fine horizontal trace banding remains under investigation. This release does not claim pixel-identical presentation to Resolve’s built-in scopes.
